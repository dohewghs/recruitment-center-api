# 🛠 Серверна частина (Backend) — Проєкт «Рекрутинговий центр»

Цей репозиторій містить серверну частину (REST API) для взаємодії між клієнтським вебзастосунком (Frontend) та базою даних PostgreSQL.

## 💻 Стек технологій
- **Середовище:** Node.js
- **Фреймворк:** Express.js
- **База даних:** PostgreSQL (хостинг на Neon.tech)
- **Бібліотеки:** `pg` (виконання SQL-запитів), `cors` (крос-доменні запити), `dotenv` (змінні середовища).

## 🔌 Документація API (Контракт для Frontend)

**Базова адреса (Base URL):**  
- Локально: `http://localhost:3000`
- У хмарі (Production): *[https://recruitment-center-api.onrender.com]*
