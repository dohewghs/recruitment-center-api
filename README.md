# 🛠 Backend API — Проєкт «Рекрутинговий центр»

Серверна частина (REST API) на базі **Node.js + Express + PostgreSQL (Neon)**, що обслуговує 16 бізнес-запитів системи рекрутингового центру.

* **Production API (Render):** `https://recruitment-center-api.onrender.com`
* **Локальна адреса:** `http://localhost:3000`
* **Детальна архітектура та контракт для Frontend:** див. `backend_architecture.md`

> **Зверніть увагу:** Сервер розміщено на безкоштовному тарифі Render. Після 15 хвилин неактивності інстанс переходить у режим сну, тому перший запит може тривати 30–50 секунд. Усі наступні запити обробляються миттєво.

---

## 📡 Основні групи маршрутів (Endpoints)

Усі 16 SQL-запитів реалізовано та згруповано за доменними префіксами:

* `/api/centers` — рекрутингові центри
* `/api/instructors` — інструктори
* `/api/inventory` — інвентар та спорядження
* `/api/marks` — оцінки та результати
* `/api/recruits` — рекрути
* `/api/sessions` — навчальні сесії
* `/api/subdivisions` — підрозділи

*(Операції додавання даних через `POST` / `INSERT` заплановано на наступний етап після узгодження форм із Frontend).*

## 🚀 Як запустити проєкт локально

Щоб розгорнути API на своєму комп'ютері для тестування або розробки, виконайте кроки нижче.

### 1. Попередні вимоги
Переконайтеся, що на комп'ютері встановлено **[Node.js](https://nodejs.org/)** (рекомендовано версію 18 або новішу).

### 2. Клонування та встановлення залежностей
Відкрийте термінал, склонуйте репозиторій, перейдіть у папку проєкту та встановіть бібліотеки з `package.json`:

```bash
git clone https://github.com/dohewghs/recruitment-center-api.git
cd recruitment-center-api
npm install
```

### 3. Налаштування змінних середовища
Створіть файл `.env` у кореневій папці проєкту (на одному рівні з `package.json`) та додайте конфігурацію (актуальний пароль для БД візьміть у розробника бекенду):

```env
PORT=3000
DATABASE_URL="postgresql://neondb_owner:ВАШ_ПАРОЛЬ@ep-cool-lab-54802077.eu-central-1.aws.neon.tech/neondb?sslmode=require"
```

> **Увага:** Файл `.env` додано до `.gitignore`, щоб паролі не потрапили в публічний репозиторій. Ніколи не комітьте реальні облікові дані!

### 4. Запуск сервера
Запустіть сервер у режимі розробки (завдяки `nodemon` він автоматично перезапускатиметься після змін у коді):

```bash
npm run dev
```

У разі успішного запуску в терміналі з'явиться:

```text
🚀 Сервер працює на http://localhost:3000
✅ Підключено до бази Neon
```

### 5. Перевірка працездатності API
Відкрийте браузер або Postman і виконайте `GET`-запит до будь-якого з реалізованих маршрутів, наприклад:
* `http://localhost:3000/api/subdivisions/max-avg-mark`
* або будь-який інший маршрут із папки `routes/`.

У відповідь сервер має повернути JSON-масив із даними з бази PostgreSQL.
