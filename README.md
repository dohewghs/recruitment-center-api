
## 🚀 Як запустити проєкт локально (Локальне середовище)

Щоб розгорнути API на своєму комп'ютері для тестування або подальшої розробки, дотримуйтесь цієї інструкції.

### 1. Попередні вимоги
Переконайтеся, що на вашому комп'ютері встановлено **[Node.js](https://nodejs.org/)** (рекомендується версія 18 або новіша).

### 2. Клонування та встановлення залежностей
Відкрийте термінал, склонуйте репозиторій та перейдіть у папку проєкту та 
встановіть усі необхідні бібліотеки, прописані в `package.json`:
```bash
git clone [https://github.com/dohewghs/recruitment-center-api.git](https://github.com/dohewghs/recruitment-center-api.git)
cd military-recruitment-api

npm install
```

### 3. Налаштування змінних середовища

Для безпечного підключення до бази даних створіть файл із назвою `.env` у кореневій папці проєкту (на одному рівні з `package.json`).

Вставте туди конфігурацію (зверніться до розробника бекенду за актуальним паролем, якщо у вас його немає):

```env
PORT=3000
DATABASE_URL="postgresql://neondb_owner:ВАШ_ПАРОЛЬ@ep-cool-lab-54802077.eu-central-1.aws.neon.tech/neondb?sslmode=require"

```

> **Увага:** Файл `.env` вже додано до `.gitignore`, тому він ніколи не потрапить у публічний репозиторій. Ніколи не робіть комміт файлів із реальними паролями!

### 4. Запуск сервера

Запустіть сервер у режимі розробки. Завдяки інструменту `nodemon`, сервер буде автоматично перезапускатися при будь-яких змінах у коді:

```bash
npm run dev

```

Якщо конфігурація правильна, у терміналі ви побачите:

```text
🚀 Сервер працює на http://localhost:3000
✅ Підключено до бази Neon

```

### 5. Перевірка працездатності API

Щоб перевірити, чи сервер успішно віддає дані з бази, відкрийте браузер або програму Postman і перейдіть за адресою:
[http://localhost:3000/api/test](http://localhost:3000/api/test)

У відповідь ви маєте отримати JSON-масив із даними з тестової таблиці.
